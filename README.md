# Telegram News Reader

**Android-приложение для прослушивания новостей из Telegram-каналов через TTS с опциональной AI-постобработкой.**

Идея простая: подписался на новостные каналы → выбрал, за какой период собрать → приложение скачало сообщения, очистило их, опционально пропустило через ИИ для сжатия, озвучило через синтез речи и проиграло как подкаст в фоне. Можно слушать в дороге, на пробежке или вместо чтения ленты.

## Возможности

- **Сбор новостей** из выбранных Telegram-каналов за период от 10 минут до 24 часов.
- **Синтез речи** через системный Android TTS или сторонние движки (Google TTS, Yandex SpeechKit, Microsoft Azure и т. п.).
- **Фоновое воспроизведение** как медиа-плеер: с уведомлением, кнопками «Пуск/Пауза/Далее», блокировкой экрана и продолжением проигрывания.
- **AI-постобработка** через OpenRouter: очистка от рекламы и мусора, краткое саммари или ужатие до одного предложения.
- **Двойная дедупликация:** удаление дублей внутри одной загрузки и между загрузками (по нормализованному отпечатку + расстоянию Левенштейна).
- **Пресеты каналов** — наборы выбранных каналов для быстрого запуска.
- **MTProto-прокси** для обхода блокировок Telegram.
- **Кэш озвученных новостей** — повторно встретившиеся новости не пересинтезируются.
- **Темы оформления** (фиолетовая / бирюзовая / светлая, тёмный режим по умолчанию).
- **Backup/restore настроек** через JSON.

## Архитектура

- **Язык:** Kotlin
- **Минимальная версия Android:** 7.0 (API 24)
- **Целевая:** Android 14 (API 34)
- **Архитектурный паттерн:** простой MVVM с ViewBinding (без отдельных ViewModel-классов — логика живёт в Activity + менеджерах в `utils/`).
- **Асинхронность:** Kotlin Coroutines.
- **БД:** Room (для списка каналов и пресетов).
- **Сеть:** OkHttp (для OpenRouter).
- **Telegram:** TDLib (нативная библиотека, AAR в `app/libs/`).
- **Аудио:** Android TTS + FFmpeg-kit (для склейки WAV-фрагментов).
- **Изображения:** Coil (аватарки каналов).
- **Даты:** ThreeTenABP (бэкпорт java.time для старых Android).

## Требования

### Для пользователя

- Android 7.0 или новее, архитектура `arm64-v8a` (большинство современных устройств).
- Аккаунт Telegram (для авторизации через TDLib).
- *(Опционально)* API-ключ [OpenRouter](https://openrouter.ai/) — если хотите включить AI-обработку.

### Для разработчика (сборка)

- Android Studio Hedgehog (2023.1.1) или новее.
- JDK 17.
- Gradle 8.x (подтянется автоматически через wrapper).
- API ID/Hash от Telegram — получить на [my.telegram.org](https://my.telegram.org) → API development tools.
- Около 200 МБ свободного места (репозиторий содержит TDLib и FFmpeg-kit как AAR).

## Установка и сборка

### 1. Клонирование

```bash
git clone https://github.com/p2petrovich/telegramnewsreader.git
cd telegramnewsreader/TelegramNewsReader
```

### 2. Получение Telegram API-ключей

1. Зайдите на [my.telegram.org](https://my.telegram.org), войдите своим телефоном.
2. **API development tools** → создайте приложение (название и платформа — любые, например «MyNewsReader» / «Android»).
3. Сохраните `api_id` (число) и `api_hash` (строка). Никому их не показывайте.

### 3. Создание `local.properties`

В корне модуля `TelegramNewsReader/` (рядом с `build.gradle`) создайте файл `local.properties`:

```properties
# Обязательно
telegram.api.id=12345678
telegram.api.hash=abcdef0123456789abcdef0123456789

# Опционально (если хотите AI-обработку)
gemini.api.key=sk-or-v1-...

# Стандартный SDK path (Android Studio пропишет сам)
sdk.dir=C:\\Users\\YourName\\AppData\\Local\\Android\\Sdk
```

> Несмотря на имя `gemini.api.key`, это именно ключ **OpenRouter** (`sk-or-v1-...`). Имя историческое.

Файл `local.properties` уже в `.gitignore` и не попадёт в репозиторий.

### 4. Альтернатива — переменные окружения

Если не хотите класть ключи в файл, можно задать их в переменных окружения:

```bash
export TELEGRAM_API_ID=12345678
export TELEGRAM_API_HASH=abcdef0123456789abcdef0123456789
export GEMINI_API_KEY=sk-or-v1-...
```

`build.gradle` сначала проверяет переменные окружения, потом `local.properties`.

### 5. Сборка

В Android Studio: **File → Open** → выбрать папку `TelegramNewsReader` → дождаться синхронизации Gradle → нажать **Run** ▶ на подключённом устройстве.

Из командной строки:

```bash
./gradlew assembleDebug          # debug-APK
./gradlew assembleRelease        # release-APK (без подписи)
./gradlew installDebug           # собрать и установить на подключённое устройство
```

Готовый APK будет в `TelegramNewsReader/app/build/outputs/apk/`.

> **Архитектура:** сборка настроена только под `arm64-v8a`. Для эмуляторов на `x86_64` нужно поправить `splits.abi.include` в `app/build.gradle`.

## Первый запуск

1. **Запустите приложение.** Появится экран авторизации Telegram.
2. **Введите номер телефона** в международном формате (`+7...`, `+380...` и т. п.).
3. **Введите код подтверждения**, который Telegram пришлёт в официальный клиент или SMS.
4. **Если включена двухфакторная аутентификация** — введите облачный пароль.
5. После успешного входа приложение загрузит список ваших каналов (только каналы, не группы и не личные чаты).

> Сессия сохраняется локально в `tdlib/` внутри приватного хранилища приложения. Повторно вводить код при каждом запуске не нужно. Отозвать сессию можно в официальном клиенте Telegram: **Настройки → Устройства**.

## Использование

### Базовый сценарий

1. **Выберите каналы** — отметьте галочками в списке те каналы, новости из которых хотите слушать.
2. **Выберите период** — слайдером от 10 минут до 24 часов («за сколько последних часов брать сообщения»).
3. **Нажмите «Загрузить и озвучить».**
4. Приложение покажет прогресс: сбор → дедупликация → фильтрация → (AI) → синтез речи.
5. По готовности откроется плеер. Дальше можно сворачивать приложение — воспроизведение продолжится в фоне.

### Управление воспроизведением

- **Из приложения** — большие кнопки «Пуск/Пауза», «Дальше», ползунок прогресса.
- **Из уведомления** — те же действия + название текущей новости.
- **С блокировки экрана** — стандартные медиа-кнопки Android (зависит от прошивки).
- **«Следующая» новость** = пропустить текущий аудио-фрагмент. Между новостями вставляется секундная пауза.

### Пресеты

Если регулярно слушаете одни и те же каналы — сохраните набор как **пресет**: иконка «звёздочка» / меню в списке каналов. В следующий раз можно одним тапом выбрать все каналы пресета.

## Настройки

Все настройки в меню «шестерёнка» в главном экране.

### Голос (TTS)

- **Голос** — выбор из доступных в системе. Откроется отдельный экран со списком, можно прослушать пример.
- **Скорость** — от 0.5× до 2.0×.
- **Высота** — pitch, от низкого до высокого.

Параметры сохраняются **отдельно для каждого голоса** — то есть для «русского женского» можно держать одну скорость, для «английского мужского» — другую.

> Если в системе нет нужного голоса, установите движок (например, **RHVoice** для русского или **Google TTS** в Play Store) и выберите его в **Настройки Android → Язык и ввод → Синтез речи**.

### Период обновления

Слайдер от 10 минут до 24 часов в шаге 10 минут. По умолчанию — 1 час.

### Тема оформления

- **Фиолетовая** (по умолчанию, тёмная).
- **Бирюзовая** (тёмная).
- **Светлая.**

### Backup / Restore

Меню «Бэкап настроек» позволяет экспортировать в JSON: список выбранных каналов, пресеты, голос, скорость, тему, прокси, настройки AI. Импорт восстанавливает всё одним нажатием. Удобно при переустановке.

## AI-постобработка (OpenRouter)

Если хочется, чтобы новости звучали короче и без рекламы, можно подключить ИИ.

### Включение

1. Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai/) → **Keys** → создайте ключ (`sk-or-v1-...`).
2. Положите ключ в `local.properties` как `gemini.api.key=` (см. раздел «Установка»). Без ключа AI отключён, тексты на сервера не уходят.
3. В настройках приложения включите **«AI-сжатие»** и выберите модель и стиль.

### Стили обработки

- **`minimal`** — только очистка. Удаляются реклама, ссылки, эмодзи, упоминания каналов, призывы «подписаться». Текст новости сохраняется дословно. Temperature 0.1.
- **`balanced`** — саммари в 2 раза короче исходника, с сохранением фактов, цифр, имён. Temperature 0.3. *Рекомендуется по умолчанию.*
- **`extreme`** — одно предложение, до 20 слов, только суть. Подойдёт для быстрых сводок.

### Модели

Поле «Модель» принимает любую строку, поддерживаемую OpenRouter. Примеры:

- `google/gemini-2.0-flash-exp:free` — бесплатно, быстро, неплохое качество.
- `openai/gpt-4o-mini` — платно, но дёшево и стабильно.
- `anthropic/claude-3.5-haiku` — платно, очень аккуратная работа с фактами.
- `meta-llama/llama-3.3-70b-instruct:free` — бесплатно, чуть медленнее.

Полный список — на [openrouter.ai/models](https://openrouter.ai/models).

### Ограничения

- Длина каждой новости обрезается до 8000 символов (защита от ошибок 400).
- Между запросами 300 мс паузы, чтобы не упереться в rate-limit бесплатных моделей.
- При ошибке 429 (Too Many Requests) — до 3 повторных попыток с экспоненциальной задержкой (2 → 4 → 6 секунд).
- Если AI вернул ошибку, новость остаётся в исходном виде — без обработки, но не теряется.

## Прокси

Если Telegram блокируется вашим провайдером, можно подключиться через MTProto-прокси.

1. Найдите MTProto-прокси (поищите в Telegram-каналах с подборками; формат — `tg://proxy?server=...&port=...&secret=...` или ссылка `t.me/proxy?...`).
2. **Настройки → Прокси** → включить, вставить host, port, secret. Можно вставить целиком ссылку — приложение само вытащит `secret=`.
3. Нажать **«Проверить»** — приложение прозвонит дата-центры Telegram (2 → 1 → 3) через ваш прокси и покажет пинг или ошибку.
4. Сохранить. Все запросы TDLib пойдут через прокси.

Только MTProto, SOCKS5/HTTP не поддерживаются.

## Как это работает внутри

Полный путь одной партии новостей от запуска до колонок:

**1. Сбор (`TelegramClient.getChannelMessagesPaginated`).** Для каждого выбранного канала параллельно (через `async/await`) запрашивается история через TDLib `GetChatHistory`. Пагинация по 100 сообщений, рекурсивно до достижения границы по времени или лимита 3000 сообщений. На канал — таймаут 15 секунд, на весь сбор — 120 секунд. Каждое сообщение приводится к формату `HH:mm — текст`. Извлекаются также подписи к фото/видео/документам.

**2. Сборка в один поток.** Сообщения каждого канала идут блоком с невидимым заголовком-маркером (`U+200B U+200C U+200B` + «Новости из канала: …»). Маркер используется дальше, чтобы отличать заголовки от новостей.

**3. Дедупликация внутри загрузки** (`TextProcessor.deduplicateAcrossChannels`). Похожие сообщения из разных каналов схлопываются.

**4. Фильтрация** (`TextProcessor.filterMessages`). Удаляются служебные строки, рекламные хвосты, дубликаты заголовков, пустышки.

**5. Дедупликация между запусками** (`Deduplicator`, опционально). Хранит отпечатки последних 500 сообщений за 60 минут. Сравнение — нормализованный текст (lowercase, без знаков препинания) + расстояние Левенштейна, порог совпадения 90%. Защита от повторов в дайджестах разных часов.

**6. Отброс «тривиалов»** (`TextProcessor.dropTrivial`). Слишком короткие или малозначимые сообщения отсеиваются.

**7. AI-обработка** (`AiProcessor.summarizeNews`, опционально). Каждое сообщение отдельным POST-запросом уходит на `openrouter.ai/api/v1/chat/completions` с промптом, выбранным по стилю. Между запросами 300 мс, при 429 — до 3 повторов. При ошибках текст остаётся неизменным.

**8. Подготовка текста к озвучке** (`TextProcessor`):
- `cleanForTts` — финальная чистка под TTS-движок.
- `deduplicateLines` — удаление повторяющихся строк внутри одной новости.
- `expandAbbreviations` — «РФ» → «Российская Федерация», «г.» → «год» и т. п.
- `normalizeNumbers` — числа в текст («1500» → «тысяча пятьсот»).
- `formatForIntonation` — расстановка пауз для естественного звучания.
- `formatForSpeech` — финальная подготовка.

**9. Синтез речи** (`TTSManager.synthesizePlaylist`). Каждая новость дробится на куски по 2800 символов (ограничение Android TTS). Каждый кусок:
- хешируется → проверка в `NewsCache` (если такой текст с такими параметрами голоса уже озвучивали — берётся готовый WAV);
- иначе синтезируется в WAV через `TextToSpeech.synthesizeToFile`;
- результат сохраняется в кэш.

**10. Склейка** (`AudioUtils` + FFmpeg). Куски одной новости + пауза 1 секунда склеиваются в один WAV-файл («главу»). Если у движка разный формат для разных голосов, FFmpeg ресемплит к общему. Между новостями вставляется тот же тихий WAV-разделитель.

**11. Воспроизведение** (`AudioPlayerService`). Foreground-сервис типа `mediaPlayback`. Получает плейлист как `ArrayList<String>` файловых путей. Использует `MediaPlayer` с `AudioAttributes(USAGE_MEDIA, CONTENT_TYPE_SPEECH)`. Обновляет уведомление 2 раза в секунду (текущая позиция в плейлисте). Транслирует прогресс через broadcast `PLAYER_PROGRESS`.

**12. Очистка.** Временные WAV (кроме кэшированных) удаляются после склейки. Файлы кэша старше 24 часов с префиксом `tts_` / суффиксом `_combined.wav` чистятся при запуске приложения (`TelegramNewsApplication.cleanupOldTempFiles`).

## Решение проблем

### «Введите код подтверждения» — код не приходит

Telegram присылает код **в официальный клиент** (если вы в нём авторизованы), и только если там нет — SMS. Проверьте папку «Telegram» в своём аккаунте. Если SMS заблокирован оператором — попросите код голосовым звонком (кнопка «Звонок» появляется через минуту).

### Каналы не подгружаются

Открыто 200 чатов из списка «Main». Если у вас больше каналов — те, что не попали в первые 200, могут не появиться. Откройте их вручную в основном клиенте Telegram, чтобы поднять в списке.

### TTS говорит на английском вместо русского

В системе не установлен русский голос. **Настройки Android → Язык и ввод → Синтез речи** → установите данные для нужного языка или другой движок (RHVoice, Vocalizer).

### «AI Error 429» — слишком много запросов

Бесплатные модели OpenRouter имеют лимит запросов в минуту. Варианты:
- подождать минуту и запустить ещё раз;
- выбрать другую модель (например, не `:free`, а платную — копейки за тысячу новостей);
- временно отключить AI (`Настройки → AI → выключить`).

### Прокси не подключается

- Проверьте, что host и port правильные (без `https://`).
- Secret должен быть в hex-формате или base64 (приложение само вытащит из ссылки).
- Кнопка «Проверить» обходит дата-центры — если ни один не отвечает, прокси мёртвый, найдите другой.

### Сборка падает с `TELEGRAM_API_ID is not a valid integer`

В `local.properties` после `telegram.api.id=` должно быть число без кавычек: `telegram.api.id=12345678`, не `telegram.api.id="12345678"`.

### Lint падает на сборке релиза

В `build.gradle` стоит `abortOnError true`. Если lint находит проблему, сборка прерывается. Поправьте предупреждения или временно поменяйте на `abortOnError false` (не рекомендуется).

### Приложение тормозит после нескольких запусков

Накапливается кэш WAV в `cacheDir`. Приложение чистит файлы старше 24 часов на старте, но если хочется вручную — **Настройки Android → Приложения → News Reader → Хранилище → Очистить кэш**. Список каналов и пресеты от этого не пострадают.

## Приватность

Полная политика — в файле [PRIVACY.md](PRIVACY.md). Кратко:

- Все данные хранятся **локально** на устройстве. Своего бэкенда у проекта нет.
- К сообщениям из Telegram приложение обращается напрямую через TDLib, минуя разработчика.
- При включённом AI тексты отправляются на **OpenRouter** (только новости, без метаданных).
- При выборе стороннего TTS-движка тексты идут на серверы выбранного провайдера.
- Ни рекламы, ни аналитики, ни Crashlytics.
