# Политика конфиденциальности

Приложение **Telegram News Reader** (далее — Приложение) создано для личного использования и ставит безопасность ваших данных в приоритет.

## 1. Какие данные мы собираем и передаем

Приложение работает преимущественно локально, но взаимодействует с внешними сервисами для обеспечения своей функциональности:

- **Telegram-данные**: Приложение подключается напрямую к серверам Telegram через официальную библиотеку **TDLib**. Ваши учетные данные (номер телефона, код) передаются только на серверы Telegram. Текст новостей загружается напрямую в зашифрованную базу данных на вашем устройстве. Приложение не имеет доступа к вашим паролям 2FA, они обрабатываются TDLib.

- **ИИ-суммаризация**: Если включена функция ИИ, текст новости (без метаданных о канале или авторе) передается выбранному провайдеру (**OpenRouter** или **Groq**). Эти данные не сохраняются Приложением на внешних серверах, но подпадают под политику конфиденциальности выбранного ИИ-провайдера.
  - **OpenRouter**: Запросы отправляются на `https://openrouter.ai/api/v1/chat/completions` с заголовками `HTTP-Referer` и `X-Title` для идентификации приложения.
  - **Groq**: Запросы отправляются на `https://api.groq.com/openai/v1/chat/completions`.
  - Передаваемые данные: только текст новости (ограничен 8000 символами), выбранная модель и стиль обработки. Метаданные канала, автор и другая служебная информация **не передаются**.

- **Синтез речи (TTS)**:
    - При использовании *системного Android TTS* обработка происходит полностью на устройстве (или согласно настройкам вашего Google-аккаунта).
    - При использовании *Edge TTS* текст передается на серверы **Microsoft** (Azure) через WebSocket для генерации аудио. Передача осуществляется в формате SSML (Speech Synthesis Markup Language).

- **Прокси**: Если вы используете MTProto-прокси, данные трафика проходят через выбранный вами прокси-сервер. Приложение поддерживает настройку списка прокси.

## 2. Локальная обработка и хранение данных

- **Локальная база данных**: Список каналов, метаданные и кэш новостей хранятся в базе данных Room и TDLib. База TDLib зашифрована 256-битным ключом.
- **Ключи безопасности**: Ключи шифрования базы данных и API-ключи провайдеров ИИ хранятся в защищенном системном хранилище `Android Keystore` с использованием `EncryptedSharedPreferences`. Это предотвращает доступ к ключам даже при наличии root-прав на устройстве.
- **Дедупликация и фильтрация**: Все алгоритмы очистки текста, удаления рекламы и поиска дубликатов (алгоритм Жаккара, якорные отпечатки) работают **полностью локально** на вашем устройстве.
- **Аудио-кэш**: Сгенерированные аудио-фрагменты новостей хранятся во внутреннем кэше приложения и автоматически удаляются при очистке кэша или переустановке.
- **Резервное копирование**: При создании бэкапа данные сохраняются в файл `telegram_news_backup_*.json` в папку `Downloads`.
    - **ВНИМАНИЕ**: Файл бэкапа содержит настройки в открытом (JSON) виде, включая номер телефона и секрет прокси (если настроен). Это необходимо для простоты восстановления. Не передавайте файлы бэкапа третьим лицам.

## 3. Аналитика и реклама

- В Приложении **полностью отсутствуют** рекламные модули, трекеры (Google Analytics, Firebase Analytics и др.) и системы автоматического сбора отчетов об ошибках.
- Мы не собираем информацию о том, какие каналы вы слушаете или какими моделями ИИ пользуетесь.

## 4. Разрешения (Permissions)

- `INTERNET`: Загрузка новостей из Telegram, работа ИИ и Edge TTS.
- `FOREGROUND_SERVICE`: Обеспечение бесперебойной работы плеера и сбора новостей в фоновом режиме.
- `READ_EXTERNAL_STORAGE` / `WRITE_EXTERNAL_STORAGE`: Работа с файлами резервных копий (на старых версиях Android).
- `POST_NOTIFICATIONS`: Отображение уведомления управления плеером (Android 13+).

## 5. Обновления

Приложение проверяет наличие новых версий на GitHub Releases. При этом передается только запрос на получение информации о последнем релизе.

## 6. Контакты

Данная политика актуальна для версии 3.0 и выше. По вопросам приватности вы можете обратиться к разработчику через GitHub репозиторий проекта.
