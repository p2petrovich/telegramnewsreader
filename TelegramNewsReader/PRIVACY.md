# Политика конфиденциальности

Приложение **Telegram News Reader** (далее — Приложение) создано для личного использования и ставит безопасность ваших данных в приоритет.

## 1. Какие данные мы собираем и передаем

Приложение работает преимущественно локально, но взаимодействует с внешними сервисами для обеспечения своей функциональности:

- **Telegram-данные**: Приложение подключается напрямую к серверам Telegram через официальную библиотеку **TDLib**. Ваши учетные данные (номер телефона, код) передаются только на серверы Telegram. Текст новостей загружается напрямую в зашифрованную базу данных на вашем устройстве.

- **ИИ-суммаризация**: При включении ИИ текст новости передается выбранному провайдеру (**OpenRouter** или **Groq**). 
  - Передаваемые данные: только текст новости (без метаданных автора/канала), выбранная модель и стиль. 
  - **Безопасность**: Ваши API-ключи хранятся в зашифрованном системном хранилище Android Keystore.

- **Синтез речи (TTS)**:
    - При использовании *системного Android TTS* обработка происходит полностью на устройстве.
    - При использовании *Edge TTS* текст передается на серверы **Microsoft** через WebSocket для генерации аудио.

- **Прокси**: При использовании MTProto-прокси данные трафика проходят через выбранный вами сервер.

## 2. Локальная обработка и хранение данных

- **Шифрование**: База данных TDLib зашифрована 256-битным ключом. Доступ к ключам шифрования и API-ключам защищен системным хранилищем Android, что предотвращает их кражу даже при наличии root-прав.
- **Локальные алгоритмы**: Дедупликация (поиск повторов), фильтрация рекламы и очистка текста работают **полностью локально** на вашем устройстве.
- **Резервное копирование**: При создании бэкапа данные сохраняются в JSON-файл в папку `Downloads`.
    - **ВНИМАНИЕ**: Файл бэкапа содержит настройки (включая номер телефона и API-ключи ИИ) в открытом виде для обеспечения возможности переноса на другие устройства. Не передавайте файлы бэкапа третьим лицам.

## 3. Аналитика и реклама

- В Приложении **полностью отсутствуют** рекламные модули, трекеры (Google Analytics, Firebase и др.) и системы автоматического сбора отчетов об ошибках.
- Мы не собираем информацию о ваших предпочтениях, каналах или истории прослушивания.

## 4. Разрешения (Permissions)

- `INTERNET`: Загрузка новостей, работа ИИ и Edge TTS.
- `FOREGROUND_SERVICE`: Работа плеера и сбора новостей при свернутом приложении.
- `POST_NOTIFICATIONS`: Управление плеером через уведомление (Android 13+).

## 5. Контакты

Данная политика актуальна для версии 3.0 и выше. По вопросам приватности вы можете обратиться к разработчику через GitHub репозиторий проекта.
