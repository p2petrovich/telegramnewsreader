# Telegram News Reader

Приложение для прослушивания новостей из Telegram-каналов с использованием ИИ для суммаризации и очистки текста. Позволяет объединять новости из нескольких источников в единый аудио-плейлист.

## Основные возможности
- **Агрегация новостей**: Чтение сообщений из выбранных Telegram-каналов за определенный период.
- **AI-обработка**: Очистка от рекламы, краткое саммари или сжатие до одной «молнии».
- **Движки TTS**: Поддержка системного Android TTS и высококачественного нейронного Edge TTS (Microsoft).
- **Фоновое воспроизведение**: Работа через Foreground Service с управлением через уведомление и экран плеера.
- **Дедупликация**: Умная фильтрация похожих новостей на основе коэффициента Жаккара.
- **Прокси**: Встроенная поддержка MTProto-прокси для обхода блокировок.
- **Гибкость**: Создание пресетов каналов и резервное копирование настроек в JSON.

## Требования
- **Android**: 7.0 (API 24) и выше.
- **Ориентация**: Приложение жестко зафиксировано в портретном режиме (`portrait`).
- **Интернет**: Необходим для загрузки новостей, работы ИИ и Edge TTS.

## Архитектура
Проект организован по классической Android-архитектуре с использованием `ViewBinding` и `Coroutines`.

### Основные компоненты (Activity):
- `MainActivity`: Основной экран со списком каналов, пресетами и настройками. Защищена от пересоздания при повороте или вызове клавиатуры (`configChanges`).
- `AuthActivity`: Экран авторизации в Telegram (номер телефона, код, 2FA).
- `PlayerActivity`: Интерфейс управления воспроизведением аудио-дайджеста.
- `VoiceSelectionActivity`: Настройка движка и голосов озвучки.

### Сервисы и менеджеры:
- `AudioPlayerService`: Foreground-сервис (`mediaPlayback`) для непрерывного воспроизведения.
- `TelegramClientManager`: Управление жизненным циклом TDLib.
- `TTSManager`: Единая точка доступа к синтезу речи (Android/Edge).
- `AiProcessor`: Логика взаимодействия с API ИИ-провайдеров.
- `Deduplicator`: Фильтрация дубликатов в истории новостей.
- `SettingsBackup`: Экспорт и импорт настроек, каналов и пресетов в JSON.

## ИИ и обработка текста
Приложение поддерживает работу через **OpenRouter** (по умолчанию) или **Groq**.

- **Модели по умолчанию**:
    - OpenRouter: `z-ai/glm-4.5-air:free` (хороший русский язык).
    - Groq: `llama-3.3-70b-versatile` (высокая скорость).
- **Стили обработки**:
    - *Minimal*: Удаление рекламы и мусора без сокращения фактов.
    - *Balanced*: Краткое саммари (сокращение в ~2 раза).
    - *Extreme*: Сжатие всей новости до одного предложения.
- **Логика**: Текст ограничивается 8000 символами. Реализованы повторные попытки при ошибке 429 (Rate Limit).

## Безопасность и конфиденциальность
- **Шифрование**: База данных TDLib зашифрована ключом, хранящимся в `Android Keystore` через `EncryptedSharedPreferences`.
- **Прокси**: Секреты прокси и номер телефона хранятся в защищенном хранилище.
- **ВАЖНО**: Резервные копии (бэкап в JSON) на текущий момент содержат чувствительные данные (номер телефона, секрет прокси) для удобства переноса. Храните файлы бэкапа в надежном месте.

## Технический стек
- **Язык**: Kotlin
- **БД**: Room (2.6.1)
- **Сеть**: OkHttp (4.12.0)
- **Изображения**: Coil (2.6.0)
- **Аудио**: FFmpeg Kit (Full GPL 6.0-2.LTS) для склейки и конвертации WAV.
- **Telegram**: TDLib (через кастомный aar).
- **Другое**: Coroutines (1.7.3), Gson (2.10.1), ThreeTenABP (1.4.6).

## Сборка проекта
Для сборки необходимо создать файл `local.properties` в корне и указать:
```properties
telegram.api.id=ВАШ_ID
telegram.api.hash=ВАШ_HASH
openrouter.api.key=ВАШ_КЛЮЧ (опционально)
groq.api.key=ВАШ_КЛЮЧ (опционально)
```
Поддерживается сборка только под `arm64-v8a` (ABI split включен для оптимизации размера).
