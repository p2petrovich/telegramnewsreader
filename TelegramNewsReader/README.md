# Telegram News Reader

Приложение для чтения новостей из Telegram каналов с использованием озвучки (TTS) и суммаризации через ИИ.

## Основные возможности
- **Сбор новостей**: Получение новых сообщений из выбранных каналов за указанный период (от 10 минут до 24 часов).
- **Озвучка (TTS)**: Синтез речи для прослушивания новостей в фоновом режиме.
- **Интеграция с ИИ**: Использование моделей через OpenRouter для очистки текста от мусора, создания кратких сводок и изменения стиля пересказа.
- **Дедупликация**: Умная фильтрация повторяющихся новостей из разных источников.
- **Управление наборами**: Создание пресетов каналов для быстрого запуска.
- **Прокси**: Поддержка MTProto прокси для обхода блокировок.

## Установка и сборка

1. Клонируйте репозиторий.
2. Получите `API_ID` и `API_HASH` на [my.telegram.org](https://my.telegram.org).
3. Создайте файл `local.properties` в корне проекта и добавьте туда свои данные:
   ```properties
   telegram.api.id=ВАШ_ID
   telegram.api.hash=ВАШ_HASH
   gemini.api.key=ВАШ_КЛЮЧ_OPENROUTER (опционально)
   ```
4. Соберите проект в Android Studio.

## Технологии
- **Язык**: Kotlin
- **Библиотеки**: TDLib, Room, Coroutines, OkHttp, Coil, FFmpeg-kit.
- **Архитектура**: MVVM (ViewBinding).
