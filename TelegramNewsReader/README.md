# Telegram News Reader

Приложение для удобного чтения и прослушивания новостей из Telegram-каналов с использованием искусственного интеллекта и синтеза речи.

## Основные возможности

- **Сбор новостей**: Получение сообщений из выбранных каналов за определенный период.
- **ИИ-сжатие**: Автоматическое создание кратких сводок новостей через API OpenRouter.
- **Синтез речи (TTS)**:
    - **Edge TTS**: Высококачественные голоса от Microsoft (требуется интернет).
    - **Системный TTS**: Локальные голоса Android (работает офлайн).
- **Параллельная обработка**: Ускоренный синтез Edge TTS и сжатие ИИ.
- **Безопасность**: Зашифрованная база данных TDLib и защита ключей через Android Keystore.
- **Бэкап**: Экспорт и импорт настроек и списка каналов.

## Настройка

Для работы приложения необходимо создать файл `local.properties` в корневом каталоге проекта и добавить следующие ключи:

```properties
# Telegram API (получить на https://my.telegram.org)
telegram.api.id=ВАШ_API_ID
telegram.api.hash=ВАШ_API_HASH

# OpenRouter API (для ИИ-сводки, получить на https://openrouter.ai)
openrouter.api.key=ВАШ_API_KEY
```

> [!NOTE]
> Edge TTS не требует дополнительных ключей и работает "из коробки" при наличии интернета.
