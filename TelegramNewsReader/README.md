# Telegram News Reader 🎧📱

**Telegram News Reader** — это инновационное Android-приложение, которое превращает вашу новостную ленту Telegram в персональный аудио-дайджест. С помощью искусственного интеллекта приложение очищает новости от информационного шума, суммирует их и озвучивает, позволяя вам оставаться в курсе событий, не отвлекаясь от дел.

## 🌟 Ключевые возможности

- **Умная агрегация**: Выбирайте любимые каналы и период (от 1 часа до нескольких суток). Приложение само соберет актуальные сообщения.
- **Интеллектуальная фильтрация**: Автоматическое удаление рекламы, ссылок, призывов к подписке и "мусорных" фраз.
- **AI-редактор**: Три режима обработки текста — от простой чистки до ультра-коротких сводок («молний»).
- **Дедупликация**: Если разные каналы пишут об одном и том же, приложение озвучит новость только один раз.
- **Аудио-плейлист**: Удобный плеер с поддержкой фонового режима, управления через уведомление и Bluetooth-гарнитуру.
- **Edge TTS**: Использование нейронных голосов Microsoft для максимально естественного звучания.
- **Наборы (Пресеты)**: Создавайте тематические группы каналов (например, «Экономика», «Технологии», «Юмор») для быстрого запуска.
- **MTProto Proxy**: Встроенный клиент для обхода ограничений сети.

## ⚙️ Технологии и алгоритмы

### 1. Дедупликация (Deduplicator.kt)
Приложение использует **индекс сходства Жаккара** для сравнения сообщений. Текст нормализуется (приведение к нижнему регистру, удаление стоп-слов, знаков препинания), после чего вычисляется коэффициент пересечения множеств слов. 
- Порог по умолчанию: **0.9** (настраиваемый).
- Работает как внутри одного канала, так и между всеми выбранными источниками.

### 2. Обработка текста (TextProcessor.kt)
Сложная многоэтапная система подготовки текста перед озвучкой:
- **Нормализация чисел**: Конвертация «10 млрд руб» в «десять миллиардов рублей».
- **Расширение сокращений**: «РФ» → «Россия», «ЦБ» → «Центробанк», «км/ч» → «километров в час».
- **Интонационная разметка**: Улучшение пауз, замена спецсимволов и форматирование списков для правильного звучания.
- **Очистка РБК/Baza**: Специализированные фильтры для удаления специфических подписей крупных новостных сетей.

### 3. ИИ-суммаризация (AiProcessor.kt)
Модуль обработки новостей с помощью языковых моделей:
- **Автоопределение языка**: Автоматически определяет язык текста (русский/английский) по соотношению кириллицы и латиницы.
- **Адаптивные промпты**: Для каждого стиля и языка используются отдельные промпты с детальными инструкциями.
- **Контроль длины выходного текста**: Динамический расчёт `max_tokens` на длины входного текста (примерно 1 токен на 3-4 символа).
- **Настройка температуры**: Минимальная температура (0.1-0.15) для максимальной точности и минимума "творчества".
- **Повторные попытки**: Автоматический retry при ошибке 429 (Rate Limit) с экспоненциальной задержкой (2с, 4с).
- **Очистка ошибок**: Функция `stripErrorPrefix` удаляет технические префиксы ошибок перед озвучкой TTS.
- **Проверка модели**: Функция `testModelAvailability` для проверки доступности выбранной модели.

## 🏗️ Архитектура системы

Приложение построено на базе современных Android-компонент:
- **UI**: Activity с использованием ViewBinding. Реактивное обновление состояния через обратные вызовы.
- **Storage**: 
    - **Room DB**: Хранение списка каналов, их метаданных и кэша.
    - **TDLib**: Зашифрованная локальная БД для работы с Telegram API.
- **Background**: 
    - `NewsService`: Координатор сбора и подготовки новостей.
    - `AudioPlayerService`: Foreground-сервис для бесперебойного аудио-потока.
- **API**: OkHttp с настроенными таймаутами и поддержкой прокси.

## 🤖 Использование ИИ (AI)

Приложение поддерживает работу с API **OpenRouter** и **Groq**. 

### Доступные провайдеры:
1. **OpenRouter** (`https://openrouter.ai/api/v1/chat/completions`)
   - Поддерживает множество моделей от разных провайдеров.
   - Требует заголовки `HTTP-Referer` и `X-Title` для идентификации.
   
2. **Groq** (`https://api.groq.com/openai/v1/chat/completions`)
   - Высокоскоростной инференс на собственных чипах LPU.
   - Оптимизирован для быстрой генерации.

### Доступные режимы (Стили):

| Режим | Temperature | max_tokens | Описание |
|-------|-------------|------------|----------|
| **Minimal** | 0.1 | Длина входа / 2 | Текст очищается от технического мусора (ссылки, теги, реклама), но все факты сохраняются дословно. Идеально для тех, кто хочет слышать оригинал без "воды". |
| **Balanced** | 0.1 | Длина входа / 3 | Классическое саммари. Сжимает текст примерно в 2 раза, выделяя суть. |
| **Extreme** | 0.15 | 60 | Режим "Молния". Оставляет только одно самое важное предложение (до 20 слов). |

### Особенности реализации:
- **Параллелизм**: Приложение обрабатывает до 3-х новостей одновременно для ускорения процесса подготовки.
- **Retry-логика**: Автоматическое повторение запроса при ошибке 429 (Rate Limit) с экспоненциальной задержкой (2с, 4с, максимум 3 попытки).
- **Ограничение входа**: Текст новости ограничивается 8000 символами для предотвращения ошибок 400.
- **Обработка ошибок**: При ошибках возвращается оригинальный текст с префиксом `[AI Error ...]`, который автоматически удаляется перед TTS.

## 🗣️ Синтез речи (TTS)

### Движки:
- **Android System TTS**: Позволяет использовать любой установленный в системе голос (Google, Yandex и др.). Работает офлайн.
- **Edge TTS**: Использует облачные нейронные голоса (Microsoft Azure). Требует интернет, но звучит как живой человек. Голоса по умолчанию: `Dmitry` и `Svetlana`.

### Оптимизация:
Приложение генерирует WAV-файлы для каждой части новости, кэширует их и склеивает в единый поток с помощью **FFmpeg**. Это позволяет мгновенно переключать треки и экономить трафик при повторном прослушивании.

## 🛡️ Приватность и безопасность

- **Android Keystore**: Ключ шифрования базы данных Telegram генерируется на устройстве и хранится в защищенном аппаратном модуле.
- **Без аналитики**: В приложении нет Google Analytics, Firebase или Crashlytics. Мы не знаем, что вы слушаете.
- **Локальные бэкапы**: Все ваши настройки и пресеты хранятся только у вас в виде JSON-файла.
- **Конфиденциальность ИИ**: При использовании ИИ-суммаризации передаётся только текст новости. Метаданные канала, автор и другая служебная информация не передаются провайдерам.

> ⚠️ **Внимание**: На текущий момент файлы бэкапа содержат номер телефона и секрет прокси в открытом виде для обеспечения простоты восстановления. Не передавайте файлы бэкапа посторонним.

## 🛠️ Сборка и разработка

### Требования к среде:
- Android Studio Jellyfish (или новее)
- JDK 1.8 / 17
- Android SDK 34 (Target), 24 (Min)

### Файл `local.properties`:
Для работы необходимо прописать API ключи:
```properties
telegram.api.id=12345
telegram.api.hash=abcdef123456...
openrouter.api.key=sk-or-v1-...
groq.api.key=gsk_...
```

### Структура проекта:
- `telegram/`: Обертка над TDLib, авторизация и загрузка сообщений.
- `tts/`: Провайдеры синтеза и управление аудио-кэшем.
- `utils/AiProcessor.kt`: Логика работы с LLM моделями (OpenRouter, Groq).
- `utils/TextProcessor.kt`: Регулярные выражения и правила трансформации текста.
- `utils/PreferenceManager.kt`: Управление настройками приложения.

### Ключевые классы:
| Файл | Назначение |
|------|------------|
| `AiProcessor.kt` | Отправка запросов к ИИ, retry-логика, автоопределение языка |
| `TextProcessor.kt` | Нормализация текста, расшифровка сокращений |
| `Deduplicator.kt` | Дедупликация новостей по индексу Жаккара |
| `NewsService.kt` | Фоновый сервис сбора новостей |
| `AudioPlayerService.kt` | Фоновый сервис воспроизведения аудио |
