# Telegram News Reader 🎧📱

**Telegram News Reader** — это инновационное Android-приложение, которое превращает вашу новостную ленту Telegram в персональный аудио-дайджест. С помощью искусственного интеллекта приложение очищает новости от информационного шума, суммирует их и озвучивает, позволяя вам оставаться в курсе событий, не отвлекаясь от дел.

## 🌟 Ключевые возможности

- **Умная агрегация**: Выбор каналов и периода сбора (от 10 минут до 24 часов).
- **Интеллектуальная фильтрация**: Автоматическое удаление рекламы, ссылок, промо-блоков и "мусорных" фраз (специальные фильтры для РБК, Baza и др.).
- **AI-редактор**: Три режима обработки текста — от простой чистки до ультра-коротких сводок («молний»). Поддержка моделей **Groq** и **OpenRouter**.
- **Продвинутая дедупликация**: Использование якорных отпечатков (числа, имена собственные, аббревиатуры) для исключения повторов одной новости из разных каналов.
- **Аудио-плейлист**: Фоновый плеер с поддержкой управления через уведомление, экран блокировки и Bluetooth.
- **Гибкий порядок воспроизведения**: 4 режима (по каналам или хронологически, новые или старые первыми).
- **Edge TTS**: Использование нейронных голосов Microsoft Azure для максимально естественного звучания.
- **Наборы (Пресеты)**: Создание тематических групп каналов для быстрого запуска.
- **MTProto Proxy**: Встроенный клиент с поддержкой списка прокси, автопереключения и проверки пинга.
- **Темы оформления**: Классическая фиолетовая, современная тиловая и светлая темы.
- **Система бэкапов**: Экспорт всех настроек, пресетов и базы каналов в JSON с возможностью быстрого восстановления по дате.

## ⚙️ Технологии и алгоритмы

### 1. Дедупликация (`TextProcessor.kt`, `Deduplicator.kt`)
Приложение использует гибридный алгоритм для поиска дубликатов:
- **Якорные отпечатки (Fingerprints)**: Выделение уникальных сущностей — чисел (суммы, даты, проценты), аббревиатур и имен собственных. Если в двух новостях совпадает ≥2 сильных якоря, они считаются дубликатами.
- **Индекс сходства Жаккара**: Запасной критерий для сравнения наборов значимых слов.
- **История**: Хранение отпечатков последних 500 новостей для исключения повторов в течение заданного окна (по умолчанию 60 мин).

### 2. Речевая подготовка (`TextProcessor.kt`)
Глубокая трансформация текста перед синтезом (TTS):
- **Нормализация чисел**: «10 млрд руб» → «десять миллиардов рублей», «$50» → «пятьдесят долларов».
- **Даты и время**: Преобразование дат в родительный падеж («1 июня» → «первого июня») и обработка диапазонов («27–29» → «от 27 до 29»).
- **Сокращения**: Раскрытие единиц измерения («мм рт. ст.», «кв. м») и новостных терминов («РФ», «ЦБ», «ВСУ», «БПЛА»).
- **Интонационная разметка**: Замена спецсимволов (‼‼‼ → «Главное...») и выделение важных слов («Срочно», «Молния») для улучшения звучания.
- **Очистка мусора**: Удаление URL, хэштегов, упоминаний, технических пометок (ред., переслано) и специфических футеров каналов.

### 3. ИИ-процессинг (`AiProcessor.kt`)
- **Параллелизм**: Обработка до 3-х новостей одновременно через систему семафоров.
- **Адаптивность**: Автоопределение языка (RU/EN) для выбора соответствующих промптов.
- **Надежность**: Retry-логика для обработки Rate Limit (429) с экспоненциальной задержкой.
- **Контроль качества**: Удаление технических префиксов ошибок ИИ перед передачей текста в TTS.

## 🏗️ Архитектура системы

- **Core**: Построено на базе **TDLib** (Telegram Database Library) для стабильной и быстрой работы с Telegram API.
- **Storage**: 
    - **Room DB**: Локальное хранилище каналов и метаданных.
    - **EncryptedSharedPreferences**: Безопасное хранение API-ключей и ключей шифрования БД.
- **Services**:
    - `NewsService`: Координатор конвейера обработки (сбор → фильтрация → дедупликация → AI → TTS).
    - `AudioPlayerService`: Foreground-сервис для непрерывного воспроизведения и управления медиа-сессией.
- **Update System**: `UpdateChecker` контролирует версии через GitHub Releases и поддерживает принудительное обновление (Kill-switch).

## 🤖 Использование ИИ (AI)

| Режим | Описание | Температура |
|-------|----------|-------------|
| **Minimal** | Удаление мусора (ссылки, теги, реклама) при сохранении всех фактов дословно. | 0.1 |
| **Balanced** | Классическое саммари. Сжимает текст примерно в 2 раза, выделяя суть. | 0.1 |
| **Extreme** | Режим "Молния". Оставляет только одно самое важное предложение. | 0.15 |

> **Безопасность**: API-ключи Groq и OpenRouter хранятся в зашифрованном виде через Android Keystore. При обработке передаётся только текст новости без метаданных пользователя.

## 🗣️ Синтез речи (TTS)

### Движки:
1. **Android System TTS**: Позволяет использовать любой установленный в системе голос (Google, Yandex и др.). Работает офлайн.
2. **Edge TTS**: Высококачественные нейронные голоса Microsoft. Поддержка настройки скорости и тембра (Pitch).

### Оптимизация:
- Генерация WAV-фрагментов для бесшовного переключения между новостями.
- Кэширование аудио для экономии трафика и мгновенного повторного прослушивания.

---

## 🛡️ Приватность и безопасность

- **Шифрование БД**: Ключ для TDLib генерируется при первом запуске и хранится в **Android Keystore**. При компрометации Keystore база данных автоматически очищается (Wipe).
- **Локальность**: В приложении нет сторонних систем аналитики или сбора логов.
- **Безопасные бэкапы**: Бэкап создаётся в формате JSON. Чувствительные данные (ключи) рекомендуется хранить отдельно.

## 🛠️ Сборка и разработка

Для сборки проекта необходимо создать файл `local.properties` и указать ключи:
```properties
telegram.api.id=ВАШ_ID
telegram.api.hash=ВАШ_HASH
openrouter.api.key=sk-or-v1-...
groq.api.key=gsk_...
```

**Ключевые модули:**
- `utils/TextProcessor.kt` — сердце логики очистки и трансформации текста.
- `utils/SecurityManager.kt` — управление ключами шифрования и Keystore.
- `telegram/TelegramClient.kt` — обертка над TDLib и работа с прокси.
- `utils/SettingsBackup.kt` — логика резервного копирования и восстановления.
